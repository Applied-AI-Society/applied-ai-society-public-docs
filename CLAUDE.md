# Applied AI Society Public Docs — Agent Instructions

## What This Repo Is

Docusaurus 3 site serving the public documentation for the Applied AI Society.

**Live site:** https://docs.appliedaisociety.org
**Base URL:** `/` (all doc paths start with `/docs/`)
**Full URL pattern:** `https://docs.appliedaisociety.org/docs/<path>`

Example: `docs/playbooks/business-owner/opportunity-brief.md` → `https://docs.appliedaisociety.org/docs/playbooks/business-owner/opportunity-brief`

## Critical: Sidebar Registration

**New docs do NOT auto-appear in the sidebar.** Every new `.md` or `.mdx` file must be manually added to `sidebars.ts` or it will be unreachable from navigation.

After creating any new doc, always update `sidebars.ts`:
- Add single docs as a string: `'playbooks/business-owner/opportunity-brief'`
- Add new sections as a category object with `label`, `link`, and `items`

A prebuild check (`scripts/check-sidebar.sh`) will warn about missing docs during `npm run build`.

## Auto-Generated Files

These files are generated at build time by prebuild scripts. Do NOT edit them manually:

- **`src/data/recentUpdates.json`** — Generated by `scripts/generate-recent-updates.sh`. Pulls the 8 most recently created or modified docs from git history. Gitignored. Do not commit manually.
- **`static/llms.txt`** and **`static/llms-full.txt`** — Generated by `scripts/generate-llms-txt.sh`. Concatenates all docs for LLM consumption. Regenerate after adding new docs with `bash scripts/generate-llms-txt.sh`.

### Sidebar nesting

The sidebar (`sidebars.ts`) nests `about/co-stewardship` and `university-partnerships` under a **Get Activated / Subscribe** category whose parent doc is `activate.mdx`. Do not re-flatten these unless asked.

## Brand Rules

- **Colors:** Orange `#E67B35`, Gold `#FFC14D`, Cream `#FAF7F1`, Olive `#5B6E4D`, Dark `#1A1A1A`
- **Tone:** Warm, human, practical. Not corporate, not hype.
- **No em dashes.** Use colons, parentheses, or separate sentences instead.

Full brand guide: `docs/brand/index.mdx`

## Asset CDN

Other repos reference brand assets via `https://docs.appliedaisociety.org/img/` URLs. Do not rename or move files in `static/img/` without checking cross-repo references.


## Footer

The footer is a single-line layout, set in `docusaurus.config.ts`:

```ts
footer: {
  style: 'dark',
  copyright: `<span class="aas-footer-inline">© 2026 Applied AI Society</span>`,
}
```

CSS lives in `src/css/custom.css` under the "Footer" comment. The orange top border and the inline layout both depend on that CSS.

## Canonical Vocabulary

AAS has a specific vocabulary. Using the canonical term over the generic one is a brand signal. Use the left column. Avoid the right column unless quoting a source that uses the generic term.

| Preferred | Avoid | Why |
|-----------|-------|-----|
| **Applied AI** (link to `/docs/concepts/applied-ai`) | treating "applied AI" as generic English; reducing it to the commercial frame only; using "AI" alone when the AAS definition is meant | Applied AI is the AAS-defined umbrella concept and the root of the whole vocabulary below: the deliberate, human-led deployment of AI so the person or organization deploying it can deliver value at a scale previously impossible, while keeping the irreplaceably human parts of the work intact. Commercial application is one important case among many; creative, civic, educational, and personal applications all qualify. Link on first substantive use in any doc, especially anywhere the reader might otherwise read "applied AI" as a generic phrase. |
| **Activation** (link to `/docs/concepts/activation`) | onboarding, literacy course, upskilling, training, enablement | Activation names the psychological and practical shift from "I have heard about AI" to "I am using it and it is changing how I work." The generic words miss that shift. |
| **Getting Jarvised** / **Jarvising** (link to `/docs/get-jarvised`) | AI training, tech coaching, AI bootcamp | Jarvising is the specific AAS verb for walking someone through the build of their own Personal Agentic OS. Use it as the name for what AAS does. |
| **Personal Agentic OS** or **Jarvis** (both canonical; link to `/docs/concepts/personal-agentic-os`) | "AI assistant," "AI agent" (in the consumer-chatbot sense), "ChatGPT" as a synecdoche | The thing AAS helps people build is sovereign, local, and compounding, not a subscription to a hyperscaler product. |
| **Hyperagent** (link to `/docs/concepts/hyperagency`) | power user, AI expert, AI-native professional | Hyperagent names the role of someone operating with an activated Jarvis. |
| **Elevator economy** (link to `/docs/concepts/the-elevator-economy`) | K-shaped economy | K implies two stable trajectories. The reality is an elevator with a cut cable. Use the elevator frame. |
| **The Omni-Crisis** (link to `/docs/concepts/the-omni-crisis`) | "AI disruption," "AI wave," "AI transformation," calling it an AI-only event | The Omni-Crisis names the convergence hitting one generation at the same time: post-WWII order collapsing, attention-economy damage, ecological devastation, rampant inequality, engineered nihilism, AI as accelerant. Do not reduce it to an AI-only narrative. AI is one current; the convergence is the whole picture. |
| **Network of activated practitioners** (used in `/docs/philosophy/jarvis-the-world-or-ai-is-doomed`) | "the AAS platform," "the AAS solution," "a single AI for everyone" | AAS does not build one centralized platform. We build the infrastructure and culture for a network of activated practitioners, each owning the system they built. Resist single-platform framing. We are the enabling layer, not the platform. |
| **The Applied AI Discipline** (link to `/docs/concepts/applied-ai-practice` or section `/docs/applied-ai-practice`) | dropping the definite article ("applied AI discipline" as a generic phrase), "AI fluency," "digital literacy," "tech literacy," "applied AI literacy" as an umbrella | The Applied AI Discipline is the AAS umbrella term for the daily, embodied work of wielding [applied AI](/docs/concepts/applied-ai) to advance your will in the world. Progressive, lifelong. **Discipline** carries the canonical-name weight (titles, h1s, frontmatter, the rung in the literacy → discipline → mastery ladder, definitional sentences like "applied AI is a discipline"). **Practice** remains a valid co-term in body prose for the verb form ("I practice applied AI daily"), daily-action framing ("daily practice," "build a practice"), and welcoming-beginner contexts. The two words coexist; pick whichever reads naturally. The person walking it is always an [**applied AI practitioner**](/docs/concepts/applied-ai-practitioner), never a "disciple." Use the definite article on the canonical name ("the applied AI discipline"); skip when an existing determiner is doing the same job ("a daily applied AI discipline," "your applied AI discipline"). |
| **Applied AI literacy** (narrow; link to `/docs/applied-ai-practice/earthshot`) | using "literacy" as the umbrella for the whole discipline | The threshold rung: baseline awareness plus a first felt experience of a real AI system operating inside your own work. This is the rung AAS can commit to on humanity's behalf. The **ladder** is literacy (what AAS earthshots) → discipline (the individual's daily work) → mastery (individual will × community × years). We cannot earthshot the discipline or mastery; we can open the door to literacy and hold it open. |
| **Applied AI Literacy Earthshot** (link to `/docs/applied-ai-practice/earthshot`) | "Applied AI Discipline Earthshot," "AAS course," "AAS curriculum" | The specific AAS commitment: the best open-source source material for applied AI literacy in the world, co-created by leading practitioners. The Earthshot is named for literacy (the bar) and not for the discipline that lives on the other side of the bar, because literacy is the only rung an organization can legitimately commit to for everyone. |
| **Applied AI practitioner** (link to `/docs/concepts/applied-ai-practitioner`) | "AI user," "AI enthusiast," "power user"; using the phrase without the canonical link on first use | Someone who wields the supercomputational power of AI to advance whatever mission they carry. Two shapes: **daily** applied AI practitioner (every knowledge worker who wants to stay relevant) and **pro** applied AI practitioner (the subset whose career is applied AI itself, archetypes catalogued at `/docs/roles`). Linking the concept doc disambiguates both senses in one place. |
| **Applied AI Society newsletter** | "Applied AI Alpha" (historical, deprecated) | The public newsletter is the Applied AI Society newsletter. Biweekly, not weekly. Historical artifacts with "Applied AI Alpha" can stay as-is; nothing new uses that name. |
| **Superprompt** (link to `/docs/concepts/superprompt`) | calling an activated, contexted, tool-equipped prompt the same thing as a fresh-chat-window prompt; using "prompt" as the unit of work in 2026 content | The AAS-canonical name for a prompt that activates the full Jarvis stack: Personal Agentic OS, tools, skill files, priming, and CRIT, all firing together. A regular prompt is the trigger; a superprompt is the trigger plus the activated system. Use this term whenever the distinction matters, especially in practitioner-facing docs. Resist the framing that prompt-engineering craft alone explains output quality. |
| **The Imagination Economy** (link to `/docs/concepts/imagination-economy`) | "AI economy," "creator economy," "creative economy" | The frame for the economy applied AI is enabling: imagination (backed by applied AI leverage and the right team) as the primary asset. The defining companies are the ones that couldn't have existed before 2026, applying AI while centering humans at the highest possible level. Use this term verbatim. Don't reduce it to "AI economy" or "creator economy" — imagination and human-centering are load-bearing. |

When AAS leadership corrects a term preference in conversation ("we say X, not Y"), add the correction to this table so the correction does not need repeating.
